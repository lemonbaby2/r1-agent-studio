# 快速开始

## 前置条件

| 项 | 要求 |
|---|---|
| Python | 3.9+（`serve.py` 只用标准库） |
| 模型服务 | [Ollama](https://ollama.com/) 或任意兼容 `/api/chat` 的网关 |
| 模型 | 默认 `qwen3-coder:30b`；显存小可换 `qwen2.5-coder:7b` |

```bash
ollama serve
ollama pull qwen3-coder:30b
```

> 不装模型也能启动、浏览界面、使用文件工具；只是对话会提示「无可用链路」。

## 启动

```bash
git clone <本仓库地址>
cd r1-agent-studio
python serve.py
```

浏览器自动打开 `http://127.0.0.1:18600/`。

自定义端口 / 不自动开浏览器：

```bash
R1_PORT=19000 R1_NO_BROWSER=1 python serve.py
```

## 第一次使用

1. 左下角显示当前模型链路（默认「本机 Ollama」）；点左侧 **链路自检** 看每条链路的探测耗时。
2. 打开内置的两条示例会话，先看一遍「思考链 / 工具代码 / 执行轨迹」长什么样。
3. 点 **新建对话**，问一句需要动手的话，例如：
   - `统计当前目录下有多少个 .py 文件，并按大小排序列出前 5 个`
   - `找出最近 3 天改动过的文件`
   - `用 python 算 1~1000 里所有质数的和，把过程写成脚本执行`
4. 右侧「执行轨迹」可逐条展开，检查每一步的参数与真实输出。

## 接远程模型网关

```bash
cp config/routes.example.json config/routes.json
# 编辑 routes.json，改成自己的地址
export R1_GW_TOKEN='你的令牌'       # Windows: set R1_GW_TOKEN=你的令牌
python serve.py
```

`auth: true` 的链路会自动带 `Authorization: Bearer <R1_GW_TOKEN>`。

## 三种运行形态

| 形态 | 命令 | 依赖 | 适用 |
|---|---|---|---|
| Web 版 | `python serve.py` | 无 | 全平台、服务器、边缘盒子 |
| 桌面窗口 | `python main.py` | `pywebview` | Windows / macOS / Linux 桌面 |
| 单文件 exe | Releases 下载 | 无 | Windows 免安装分发 |

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 「未找到可用链路」 | Ollama 没起，或模型链路地址不对 → 点「链路自检」看明细 |
| 模型不调工具、直接编答案 | 换用支持 tool-calling 的模型；本项目会自动降级为文本协议，但效果差 |
| 端口被占 | `serve(0, host)` 会在 18600–18699 里自动挑空口；或设 `R1_PORT` |
| 命令被拒绝 | 命中 `tools.guard()` 黑名单（格式化、递归删除等），属预期行为 |
| 界面能开但对话卡住 | 查看 `/api/health` 与「链路自检」；流式响应超时默认 600s |

## 停止

`Ctrl+C`（`serve.py` 会 `server_close()`）。
