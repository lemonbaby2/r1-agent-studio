### ⭐ 官方单行本 PDF 的人工下载（2 分钟，最可靠）

1. 浏览器打开 `http://epub.cnipa.gov.cn/`（**用 HTTP**，不要用 HTTPS；挂瑞数防护，命令行/curl 过不去，真人浏览器可以）。
2. 在「公布公告查询」里输入**申请公布号**，例如 `CN122756908A`。
3. 结果里点「发明专利申请」进入详情。
4. 点右上角 **「下载 PDF」/「全文图像」**，得到 CNIPA 官方单行本。

> ⚠️ 该站有动态 JS 挑战：自动化脚本恒返 `202`，带 Cookie 二次请求仍 `202`。
> **要官方原件就只能人工点**，这是设计如此，不是网络故障。

## 二、美国官方（PDF 原件最容易自动下载，已验证）

| 网站 | 地址 | 说明 |
|---|---|---|
| **USPTO Patent Public Search** | `https://ppubs.uspto.gov/pubwebapp/` | 检索美国专利/申请，带 PDF 下载 |
| **USPTO 官方 PDF 直链端点** | `https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/<号码>` | ⭐ **无需登录、直接返回 PDF 原件** |
| Patent Center | `https://patentcenter.uspto.gov/` | 申请流程管理（需账号） |
| USPTO Open Data / PatentsView | `https://developer.uspto.gov/` · `https://patentsview.org/` | 批量数据 / API |

**直链号码规则**（把公开号里的斜杠和字母去掉）：

| 公开号 | 直链号码 |
|---|---|
| `US 2026/0080335 A1` | `20260080335` |
| `US 2026/0300001 A1` | `20260300001` |
| `US 12,710,982 B1` | `12710982` |

```bash
curl -L -o US_20260300001.pdf \
  "https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/20260300001"
```

> 本项目中三篇 2026 年参考专利、以及 2026 年 10 月新公开的对比文件，
> 都是从这个官方端点下的 `%PDF-1.2` 图像扫描原件，首页著录项目已逐项核验。
> 注意：USPTO 原件是**图像扫描版，无文本层**，权威但不便全文检索。

> Google Patents 的 PDF 直链形如
> `https://patentimages.storage.googleapis.com/<hash>/<公开号>.pdf`，
> **hash 必须从页面 `<meta name="citation_pdf_url">` 里取**，简化路径 `/pdfs/<号>.pdf` 一律 403。

## 六、给老师的最短路径

- **要中文官方单行本** → 浏览器开 `http://epub.cnipa.gov.cn/`，按上面 4 步手动下。
- **要能自动批量下的官方 PDF** → 走 USPTO `image-ppubs` 直链（本项目脚本已验证）。
- **要快速看中文摘要和技术要点** → 智慧芽 Eureka / 天眼查 / 金融界专利快讯。
- **要查新、写对比文件** → Google Patents（若网络通）+ Espacenet + 上面的中文站交叉核对著录项目。

> ⚠️ 第三方站的内容是**整理件**，申请/诉讼/无效程序请以 CNIPA 官方单行本为准。
